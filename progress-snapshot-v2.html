如何复现验证

  • 单测：python -m unittest discover -s eval-skill/tests
  • mock 端到端：python eval-skill/scripts/eval.py run --skill <skill> --fixture eval-skill/fixtures/edit-article-clarity --cli mock
  • CI 门禁：同上 + --ci（exit 0/1）
  • 失败路径：EVAL_MOCK_BEHAVIOR=fail + --ci（exit 1）
  • 报告：python eval-skill/scripts/report.py → runs/report.html
